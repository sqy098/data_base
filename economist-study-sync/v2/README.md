# 经济师刷题助手 · 双端学习记录同步

此目录专用于经济师刷题助手网页端和Android端的学习记录，不存题库、扫描卷原图、GitHub访问令牌或配对加密密钥。

- 分支：`economist-study-sync`，避免触发主分支原有网站发布流程。
- 每台设备写入独立的 `device-<随机设备ID>.json`。
- 文件内容使用AES-256-GCM加密并校验，密钥只在两端本机和用户保管的配对文件中。
- 作答、报告按唯一ID合并；收藏、笔记等保留删除标记，同时修改的版本可在软件中核对。
- 访问失败时保留本机待同步记录，联网并打开应用后重试。
- 独立网页或APK不能复制ChatGPT插件的授权，首次在每台设备同步设置中配置仅限此仓库、Contents读写权限的GitHub访问令牌。

配对文件及访问令牌不应提交到此仓库。既有`data/`、`site/`及工作流文件不受此功能修改。
